# The Unsent Internet

A small, nostalgic corner of the web where people anonymously leave the messages they never sent.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run lint
npm run build
```

## Status

Stage 1 (visual system and homepage) uses sample notes from `src/lib/mock-notes.ts`. Writing, discovery, the database and moderation arrive in later stages.
